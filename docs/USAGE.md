# 使い方

Pinshot の操作の一覧です。概要は [README](../README.md) を見てください。

初めて起動すると、使い方と画面収録の許可を案内する画面が出ます（メニューバーの「使い方と許可…」からも開けます）。

## キャプチャ

| 操作 | 内容 |
|---|---|
| `⌘⇧2`（設定で変更可） | キャプチャを始める |
| （初期設定）| 画面はそのままでカーソルが十字になり、横に座標が出る。ドラッグした範囲はうっすら灰色。クリックしただけでは撮らない |
| 画面の下のバー | 範囲 / ウィンドウ / 画面全体 / スクロール ｜ 録画 ｜ タイマーを切り替える（いつも出る。録画は区切り線で分ける） |
| 設定の「範囲を選ぶ画面」を「くわしく」 | 画面を暗くし、ルーペと画面いっぱいの十字線も出す |
| `space` | 範囲 ⇄ ウィンドウを切り替える |
| 範囲：ドラッグ | 範囲を選ぶ（ルーペと十字線で細かく合わせられる）。クリックしただけでは撮らない（ウィンドウを撮るときは、ウィンドウのモードにする） |
| ウィンドウ：クリック | そのウィンドウだけを撮る（ほかのウィンドウに隠れていても、中身が撮れる） |
| 画面全体：クリック | その画面を撮る（半分の大きさで浮かせる） |
| `esc`・右クリック | やめる |

メニュー（ほかのアプリのメニューバーのメニューや、右クリックのメニュー）を開いたままショートカットを押すと、開いているメニューごと撮れます。メニューを開いている間は macOS がショートカットを止めることがあるため、確実に効かせるには、設定の「一般」でアクセシビリティを許可してください。

## スクロールキャプチャ

ブラウザなど、スクロールしないと全体が見えないものを 1 枚の縦長の画像にします。

1. メニューの「スクロールキャプチャ」（ショートカットも可）か、モードバーの「スクロール」を押す。撮りたいウィンドウにマウスを乗せると、撮るスクロール領域（ブラウザならツールバーを除いたページの部分）を青い枠で示すので、そこをクリックする。クリックしたウィンドウを前に出してから撮り始める（ドラッグで範囲を選ぶこともできる）
2. 自動で下へスクロールしながら撮り、いちばん下まで来たら終わる。操作パネルの「完了」か `esc` で、途中で終えることもできる
3. つないだ画像が、画面に収まる大きさで浮かぶ

- スクロール領域を見つけて自動でスクロールするには「アクセシビリティ」の許可が必要です（操作パネルの「アクセシビリティを許可…」から）。許可がないとき・領域が見つからないときは、クリックでウィンドウ全体、ドラッグでその範囲を撮ります。許可するまでは、自分でゆっくり下へスクロールすれば、同じようにつなぎます
- 自動スクロール中にマウスを枠の外へ出したとき・ほかのウィンドウが重なったときは止まり、戻すと続きます
- うまくつなげないときは、少し戻して量を減らしながらやり直します。それでもつなげないとき（動き続ける広告・動画など）は自動をやめるので、自分でゆっくりスクロールするか「完了」を押してください
- 固定ヘッダー・フッターは 1 回だけ残します。長さは 30,000 ピクセルまでです

メニューバーのアイコンからは、次も選べます。

- 範囲 / ウィンドウ / 画面全体 / スクロールキャプチャ
- タイマーでキャプチャ（3・5・10 秒後）
- ウィンドウを選んでキャプチャ（開いているウィンドウの一覧から直接撮る）
- クリップボードの画像を浮かせる

## 画面の録画

メニューバーの「録画」の「画面を録画」（ショートカットも割り当てられる）か、範囲を選ぶ画面の下のバーの「録画」で始めます。

| 操作 | 内容 |
|---|---|
| ドラッグ | その範囲を録画する |
| クリック | マウスの下のウィンドウを録画する（ウィンドウがない所では、その画面全体）。録画するものを赤い枠で示す |
| タイマー | 選んでから 3・5・10 秒後に録画を始める |

録画している間は、範囲の外側に赤い点線の枠が、近くに操作パネル（● 経過時間・停止・やめる）が出ます。枠と操作パネルは録画に写りません（浮かせた画像は写ります）。メニューバーのアイコンは赤い ● になり、メニューの「画面を録画」は「録画を止める」に変わります。

| 止め方 | 内容 |
|---|---|
| 操作パネルの「停止」・メニューバーの「録画を止める」・同じショートカット | 止めて、録画を浮かせて再生する |
| 操作パネルの「やめる」 | 止めて、録画を捨てる |
| 10 分たつ | 自動で止める（残り 1 分になると、操作パネルで知らせる） |

止めると、録画を浮かせて、その場でくり返し再生します（ドラッグで動かせる）。下のバーで、次のことができます。

| ボタン | 内容 |
|---|---|
| コピー | 録画のファイルをクリップボードに入れる（Finder やチャットなどに貼り付けられる） |
| 保存 | MP4 で保存する（保存の設定に合わせる） |
| GIF で保存 | GIF を作って保存する（長い辺は 800 ピクセルまで、1 秒に 10 コマ。長い録画はコマを減らして軽くする） |
| Finder で表示 | 録画のファイルを Finder で見せる |
| × | 閉じる（録画はアプリの中に残る。下の「保存したものと、アプリが残すもの」） |

録画している間は、ほかのキャプチャはできません（範囲を選ぶ画面が録画に写ってしまうため）。マウスのカーソルは録画に写ります。音は録りません。

### 保存したものと、アプリが残すもの

| | 保存したもの（PNG・GIF・MP4） | アプリが残すもの（撮った画像の履歴・読み取った文字の履歴・録画） |
|---|---|---|
| できるとき | 「保存」「GIF で保存」を押したとき | 撮ったとき・読み取ったとき・録画を止めたとき（自動） |
| 置き場所 | 設定の「保存」の保存先（初期設定は「ピクチャ」の中の `Pinshot`（`~/Pictures/Pinshot`。なければ作る）。中を種類ごと・月ごとのフォルダに分けることもできる） | `~/Library/Application Support/Pinshot`（History・Recordings） |
| 削除 | Pinshot は削除しない | 設定の「履歴」の期間と数から外れた古いものを、自動で削除する（すべて削除もできる） |
| 見る所 | Finder | 履歴のウィンドウ・録画の窓・設定の「履歴」 |

## 浮かせた画像

| 操作 | 内容 |
|---|---|
| 画像の下の操作バー | 左から、動かすつまみ（✙。ドラッグで画像を動かす）・画像の不透明度（スライダー）・表示の拡大率（押すと一覧）・コピー・保存・撮った画像の履歴・そのほかのメニュー（…）・「編集」 |
| 不透明度・拡大率 | 編集していないときは操作バー、編集中はツールバーの、どちらも「コピー・保存」の左にいつも出ています |
| 操作バーの「編集」 | 編集モードに入る（編集中はツールバーの、同じあたりにある「完了」で終える） |
| 左上の外側の × | 画像を書き込みごと閉じる（編集中も出る。「閉じた画像を戻す」で戻せる） |

操作バーは、画像を隠さないよう、どんな大きさの画像でもいつも画像の下に出ます。画像をドラッグで画面の下の方へ動かしたり、拡大したりして画像の下に余白がなくなったときは、画面のいちばん下に出ます（編集モードのツールバーも同じです）。閉じるボタン（×）は、画像を隠さないよう、編集中も含めていつも画像の左上の外側に出ます（画面の端では右上や横に回ります）。画像がとても小さく、中に入らない部品も画像の外に出ます（「コピーしました」などのお知らせと編集中の書き込みのバーは上）。操作バーは常に表示されます（設定の「画像」で「マウスを乗せたときだけ」「表示しない」にもできます）。押せるものにマウスを乗せると、カーソルが指の形になります。

| 操作 | 内容 |
|---|---|
| ドラッグ | 動かす（カーソルは手の形） |
| 端・角をドラッグ | 縦横比を保ったまま大きさを変える（反対側の端は動かない） |
| スクロール・ピンチ | 拡大・縮小 |
| `⌘` か `⌥` + スクロール・操作バーのスライダー | 画像の不透明度を変える（画像の真ん中にゲージが出る） |
| `⌥` を押しながらドラッグ | 画像をほかのアプリや Finder にドラッグ＆ドロップ |
| 矢印キー（`shift` で 10pt） | 少しずつ動かす |
| ダブルクリック・`⌘E` | 編集モードに入る |
| 右クリック（操作バーの「…」も同じ） | 見出しで分けたメニュー：編集する / **コピー・保存**（コピー・コピーして閉じる・保存…）/ **文字の読み取り**（文字をコピー ⇧⌘T・範囲を選んで文字をコピー…）/ **見た目**（不透明度 ▸・拡大率 ▸（実際のサイズ・25〜400%）・背景を付ける）/ **置き方・表示**（最前面に表示・クリックを透過する・画像の下に操作バーを出す）/ 撮った画像の履歴… / 閉じる |
| `⌘C` / `⌘⇧C` / `⌘S` / `⌘W` / `⌘0` | コピー / コピーして閉じる / 保存 / 閉じる / 実際のサイズ |

「クリックを透過する」にすると、画像の下のアプリをそのまま操作できます（なぞって描くときなどに）。解除はメニューバーの「クリック透過をすべて解除」から行います。

終了したり Mac を再起動したりしても、浮かせていた画像は次に起動したときに元の場所に戻ります（書き込み・トリミング・拡大率・不透明度・背景・最前面の設定ごと）。閉じた画像（最大 10 枚）も「閉じた画像を戻す」で戻せます。画面の並びが変わっていたら、見える画面の中に戻します。編集中・クリック透過中だった画像は、ふつうの状態で戻ります。戻したくないときは、設定の「画像」でオフにしてください（置いていた画像もすぐ削除します）。

### 文字の読み取り

右クリック（か操作バーの「…」）の「文字をコピー」（⇧⌘T）で、画像の文字を読み取ってクリップボードに入れます。「範囲を選んで文字をコピー…」を選ぶと、画像の上をドラッグした範囲だけを読みます（クリックだけなら全体、esc でやめる）。日本語と英語を読めます。書き込み（矢印・文字など）は読まず、元の画像で読みます。トリミングしているときは、見えている範囲だけを読みます。読み取りは macOS の機能（Vision）で Mac の中で行い、ネットには送りません。撮った画像の履歴の右クリックにも「文字をコピー」があります。

読み取っている間は、読む範囲のまわりが暗くなり、光の帯が上から下へ流れます。読み取れたら、文字のあった場所が光ったあと、読んだ範囲の下に文字のあった場所のすぐ下に、吹き出しで読み取った文字が出ます（文字はもうクリップボードに入っています）。

| 吹き出しの操作 | 内容 |
|---|---|
| 文字を直して「更新してコピー」（⌘↩） | 文字を直すと、ボタンが「コピー」から「更新してコピー」に変わる。押すと、読み取った文字の履歴とクリップボードを直した文字にする（何度でも直せる）。履歴を残さない設定のときは「直してコピー」 |
| 「履歴で見る」 | 履歴のウィンドウの「文字」を開き、その文字を選んで見せる |
| 「閉じる」・esc | 閉じる。ほかの所を押しても、時間がたっても閉じない |
| 上の「☐ 外を押したら閉じる」 | オンにすると、吹き出しの外を押したときにも閉じる（設定の「画像」と同じもの。切り替えると、出している吹き出しにもすぐ効く） |

文字が見つからないときは、枠がオレンジ色に揺れて「文字が見つかりませんでした」と出ます。読み取った文字は、履歴（「文字」）にも残ります。

## 編集モード

| キー | ツール |
|---|---|
| `V` | 選択（書き込みを選ぶ・動かす・`delete` で削除・ダブルクリックで文字を直す。`shift` + クリックで複数選択） |
| `R` / `O` / `A` | 四角 / 楕円 / 矢印（`shift` で正方形・正円・45° ごと） |
| `P` / `H` | ペン / 蛍光ペン（`shift` でまっすぐ） |
| `K` | 文字マーカー（ツールバーでは、描くとは別の 1 つのボタン。画像の文字の上をドラッグすると、文字の高さと幅に合わせて引く。下の「文字マーカー」） |
| `T` | 文字（入力している間、枠は文字に合わせて横に伸び、画像の右端に届くと折り返して下に伸びる。shift + return で改行、return で確定。入力の途中で大きさを変えると、選んでいる部分か、そこから先の文字だけが変わる。枠線：なし・白・黒・ラベル） |
| `N` | 番号（クリックするたびに 1, 2, 3…。削除すると後ろの番号が詰まる。大きさ・デザイン・表記・フォントを選べる） |
| `S` | スポットライト（範囲の外を暗くする） |
| `M` / `B` | モザイク / ぼかし |
| `C` | トリミング（`⌘Z` で戻せる） |

| 操作 | 内容 |
|---|---|
| ツールバーの並び | 2 つのバーに分かれる。上は、編集に入る前と同じ操作バー（違うのは「編集」が「完了」になることだけ）。下は道具のバー（ツール・色・スタイル・背景・元に戻す / やり直す・表示） |
| ツールバーの 2 行目 | 道具の段のすぐ下に、ツールごとのオプション（下の表。どれも同じ形のボタンの並び）。ツールバーの幅は変わらず、入りきらないときは 2 行目が折り返す |
| 書き込みを選ぶ・描き終える | つまみが出て、矢印は始点・終点、四角などは角・辺をドラッグして形を直せる（文字マーカーも。文字との位置がずれたときに手で直せる） |
| ツールバーのボタンにマウスを乗せる | ツールバーの下に説明が出る |
| 上のバーの左端のつまみ（✙）・`space` か `⌘` を押しながらドラッグ | 画像を動かす |
| 選択ツールで何もない所をドラッグ | 画像を動かす |
| 書き込みを選んで色・太さ・オプションを押す | その書き込みに反映する |
| 矢印キー | 選んだ書き込みを少しずつ動かす |
| `1`〜`6` / `[` `]` | 色 / 太さ（文字なら大きさ） |
| `⌘A` / `⌘D` / `⌘]` `⌘[` | すべて選択 / 複製 / 前面へ・背面へ |
| 選んだ書き込みの上のバー | 複製・前面へ・背面へ・削除 |
| ツールバーの「スタイル」（パレットのアイコン） | 保存したスタイル（色・不透明度・太さ・オプション・文字の大きさ）が名前付きで並び、選ぶと呼び出す。「いまのスタイルを保存…」で名前を付けて保存（数の制限なし）。名前を変える・上書き・削除もここから。どの画像からも同じ一覧 |
| ツールバーの「背景」（額縁のアイコン） | 押すと、ツールバーの 2 行目に背景のオプションが出る。「なし / 付ける」を選び、付けたときだけ色・余白・角の丸み・影を選べる。書き出しも同じ見た目。「次の画像にも使う」で、いまの背景を、これから浮かせる画像にも最初から使う（初期設定にする）。もう一度押すか、ツールを選ぶと閉じる |
| ツールバーの「表示」メニュー（≡） | 画像から切り離す・ボタンに乗せたら説明を出す |
| ツールバーの ▾ 付きボタン | 似たツール（図形＝四角・楕円、描く＝ペン・蛍光ペン、隠す＝スポットライト・モザイク・ぼかし）と色は、1 つのボタンにまとめてある。押すと最後に使ったもの、▾ でほかを選ぶ |
| ツールバーのボタンにマウスを乗せる | 説明がポップアップで出る |
| 文字の大きさの数字を押す | 数字を入力できる（return で決定、esc でやめる） |
| `⌘Z` / `⌘⇧Z` | 元に戻す / やり直す |
| `esc`・`⌘E`・ツールバーの ✓ | 編集を終える（選んでいるときは、`esc` でまず選択を外す） |

- 色は 6 色に加えて、「＋」からカラーパネルでオリジナルの色を選べます（スポイトで画面の色も拾える）。選んだ色は 3 つまで並んで残ります
- 文字の入力中は、ツールバーの文字の大きさに、入力カーソルの位置の大きさ（範囲を選んでいるときは、その中でいちばん大きい大きさ）が出ます

ツールバーの 2 行目（オプション）は、ツールごとに次のものを選べます。太さなどはツールごとに覚えます。

| ツール | オプション |
|---|---|
| 四角 | 線の太さ（1〜16pt）・角（なし / 小 / 大）・塗り（なし / 半透明 / 塗りつぶし）・不透明度 |
| 楕円 | 線の太さ・塗り・不透明度 |
| 矢印 | 線の太さ・矢じり（始点 / 終点をそれぞれオン・オフ。両方オフなら線）・形（三角 / 山形）・矢じりの大きさ（小〜特大）・不透明度 |
| ペン / 蛍光ペン | 線の太さ・不透明度 |
| 文字マーカー | 種類（蛍光ペン / 下線 / 取り消し線 / 囲み）・余白（蛍光ペンと囲み。文字からの余白：なし / 小 / 中 / 大）・線の位置（下線と取り消し線。高め〜低めの 5 段。変えると、この画像のすべての文字マーカーがそろう）・線の太さ（蛍光ペン以外）・不透明度 |
| 文字 | 見本（いまの設定で、次に入力したらどう見えるか）・大きさ・フォント（Mac に入っているフォントから選ぶ）・縁取り（なし / 白い縁 / 黒い縁 / ラベル）・縁取りの太さ・マーカー（なし / 蛍光ペン / 下線 / 取り消し線 / 囲み。文字マーカーと同じ描き方で、文字の行ごとに引く。縁取りと組み合わせられる）・マーカーの色（6 色。初期設定は黄色）・不透明度 |
| 番号 | 大きさ・デザイン・表記・フォント・不透明度 |

ツール・色・太さ・オプションは、次に浮かせる画像にも引き継ぎます。

### 文字マーカー

画像の文字に合わせて、蛍光ペン・下線・取り消し線・囲みを引きます（自由に引きたいときは、これまでの蛍光ペン `H` を使います）。

- 文字マーカーを選ぶと、画像の文字の位置を調べます（初めの 1 回だけ。Mac の中で読み、書き込みは見ずに元の画像で読みます）
- 文字の上をドラッグすると、文章を選ぶときと同じように、始めた文字から終えた文字までを、文字の高さと幅に合わせて引きます。行をまたぐと行ごとに引きます（となりの段の文字は含めません）
- 文字のない所から引き始めたときは、ドラッグした所にまっすぐ引きます
- 引いたあとは、ほかの書き込みと同じく選んで動かす（選択ツールでドラッグ・矢印キー）・種類や色を変える・削除することができます
- 引いた直後は選んだ状態になり、四隅と辺の真ん中のつまみで、文字との位置や大きさを手で直せます（複数行は、各行をまとめて伸び縮みします）

## 履歴

撮った画像と読み取った文字は、自動で履歴に残ります。履歴のウィンドウの上の「画像 / 文字」で切り替えて見ます（かっこの中は数）。

### 撮った画像

撮った画像（範囲・ウィンドウ・画面全体・タイマー・スクロール）は、自動で履歴に残ります。日付ごとに縮小画像を並べた一覧は、次のどこからでも開けます。

- メニューバーの「撮った画像の履歴…」（ショートカットも割り当てられる）
- 画像の下の操作バーと、編集モードのツールバーの、時計のボタン
- 浮かせた画像の右クリックメニュー

一覧の上の切り替えで、表示方法を選べます（設定の「履歴」でも選べ、次に開いたときも同じ表示になります）。

| 表示方法 | 内容 |
|---|---|
| 大きいサムネイル | 大きめの縮小画像を並べる（初期設定） |
| 小さいサムネイル | 小さい縮小画像をたくさん並べて見渡す |
| リスト | 1 行に 1 枚。小さい縮小画像・時刻・大きさ・容量を並べる（↑ ↓ でも選ぶ） |

| 操作 | 内容 |
|---|---|
| クリック / ⌘ + クリック / shift + クリック / ⌘A | 1 枚を選ぶ / 足す・外す / 範囲で選ぶ / すべて選ぶ（← → でとなりへ、esc で選択を解除） |
| ダブルクリック・return | マウスのある画面の真ん中に、もう一度浮かせる（選んだものすべて。少しずつずらして重ねる）。その画像がもう浮いているときは、増やさずに前に出す（撮った直後に浮かせた画像も同じ） |
| マウスを乗せる | 縮小画像の右上に、浮かせる・コピー・削除のボタンが出る |
| 右クリック | 浮かせる・コピー・保存…・Finder で表示・履歴から削除（選んでいれば、選んだものすべて） |
| ドラッグ | ほかのアプリへ画像を渡す |
| 選んで delete / ⌘C | 選んだものをまとめて履歴から削除する（2 枚以上は確かめてから）/ コピー |
| 選んでいるときの下の帯 | 「N 枚を選択中」と、浮かせる・コピー・保存…（2 枚以上はフォルダにまとめて）・削除 |
| 下の「すべて削除…」 | 履歴をすべて削除する（確かめてから） |

残すのは元の画像だけで、書き込みは残りません。クリップボードから浮かせた画像も履歴には入りません。

### 読み取った文字

「文字をコピー」で読み取った文字は、読み取った範囲の画像と一緒に、自動で履歴に残ります（同じ文字をもう一度読んだときは、1 件にまとめて先頭に移します）。履歴のウィンドウの「文字」のほか、メニューバーの「読み取った文字 ▸」、吹き出しの「履歴で見る」から開けます。

一覧の上の切り替え（探す欄の横）で、表示方法を選べます（設定の「履歴」でも選べ、次に開いたときも同じ表示になります）。

| 表示方法 | 内容 |
|---|---|
| 詳しく | 時刻・文字数と、大きめの読み取った画像（どの画像の文字か）と文字の最初の 5 行 |
| 標準 | 小さな読み取った画像・時刻・文字数と、文字の最初の 2 行（初期設定） |
| コンパクト | 画像なしで 1 行（時刻と最初の行）。たくさんの中から探すとき |

右の欄には、選んだ文字の全文が出ます（間の線はドラッグで動かせます）。

| 右の欄 | 内容 |
|---|---|
| 1 件を選んだとき | 上に日時と「削除」。その下に「読み取った画像」（見出しの横に「浮かせる」「画像をコピー」。画像はドラッグでほかのアプリへ渡せる）と「文字」（見出しの横に文字数と「コピー」）。文字はそのまま直せる。吹き出しと同じく、直しただけでは保存せず、ボタンが「更新してコピー」（⌘↩）に変わり、押すと履歴とクリップボードを直した文字にする。直している途中でほかを選んでも、直した文字は覚えていて（一覧に「編集中」と出る）、戻ると続きから直せる（ウィンドウを閉じると捨てる）。文字の右クリック：切り取り・コピー・ペースト・すべてを選択・全文をコピー（直しているときは「更新してコピー」） |
| 2 件以上を選んだとき | 上に「つなげてコピー」「削除」。その下に、つなげてコピーする文字（空の行をはさんでつなげたもの） |

| 操作 | 内容 |
|---|---|
| 上の「文字を探す」 | 打った文字を含むものだけに絞る（大文字と小文字、ひらがなとカタカナの違いは見ない） |
| クリック / ⌘ + クリック / shift + クリック / ⌘A | 1 件を選ぶ / 足す・外す / 範囲で選ぶ / すべて選ぶ（↑ ↓ でとなりへ、esc で選択を解除） |
| ダブルクリック・return・⌘C | コピーする（2 件以上は、空の行をはさんでつなげる） |
| 行の右のボタン | コピー・削除（いつも出ている） |
| 右クリック | コピー・読み取った画像を浮かせる・読み取った画像をコピー（1 件のとき）・履歴から削除（選んでいれば、選んだものすべて） |
| ドラッグ | ほかのアプリへ文字を渡す |
| 選んで delete | 選んだものをまとめて履歴から削除する（2 件以上は確かめてから） |
| 下の「すべて削除…」 | 読み取った文字の履歴をすべて削除する（確かめてから） |

履歴（画像・文字）から浮かせた画像は、1 つの履歴につき 1 つだけです。もう浮いている画像をもう一度浮かせようとすると、新しく増やさずに、浮いている画像を前に出して「すでに浮かせています」と知らせます（閉じたあとなら、また浮かせられます）。

### 残し方

設定の「履歴」で、撮った画像と読み取った文字のそれぞれについて、残すかどうか・残す期間（1 日 / 1 週間 / 30 日 / ずっと）・残す数（50 / 100 / 300 / 1000 件）を別々に選べます（例: 画像は 30 日、文字はずっと）。初期設定はどちらも 30 日・100 件で、外れたものは古い順に自動で削除されます。履歴は `~/Library/Application Support/Pinshot/History` に置きます（画像は PNG、読み取った文字は `texts.json` と、読み取った範囲の画像 `<id>.text.png`）。

## メニューバー

カメラのアイコンを押すと、次のメニューが出ます。項目にはアイコンが付き、割り当てたショートカットも横に出ます。

- **キャプチャ**：範囲 / ウィンドウ / 画面全体 / スクロール、タイマー（3・5・10 秒後）、開いているウィンドウを選んでキャプチャ
- **録画**：画面を録画（録画中は「録画を止める」）
- **撮った画像の履歴**（枚数も出る）：撮った画像の履歴…、読み取った文字 ▸（最近読み取った 10 件。押すとコピー。いちばん下の「文字の履歴を開く…」で一覧へ）
- **浮かせた画像**（浮かせている枚数も出る）：クリップボードの画像を浮かせる、閉じた画像を戻す（最大 10 枚）、すべての画像を前に出す、すべての画像を閉じる。クリックを透過している画像があるときだけ「クリック透過をすべて解除」も出る
- **設定…**、**使い方と許可…**、**Pinshot について**、終了
- 画面収録の許可がないときは、いちばん上に「画面収録の許可が必要です…」が出る

## 設定（メニューバーの「設定…」）

上のタブで 5 つに分かれています。ウィンドウの名前は、選んでいるタブの名前になります。

| タブ | 項目 |
|---|---|
| 一般 | 見た目（システム / ライト / ダーク。ツールバー・メニュー・設定などの色）、範囲を選ぶ画面（シンプル / くわしく＝画面を暗くしてルーペと十字線）、撮ったらクリップボードにもコピー、許可（画面収録・アクセシビリティの状態と「許可する…」）、ログイン時に起動、バージョン・使い方 |
| 画像 | 常に最前面に表示、浮かせたときの不透明度、閉じるボタンと操作バーの出し方（常に / マウスを乗せたとき / 表示しない）、操作バーを出すか（オフにすると、ダブルクリックで編集するまで画像の下に何も出さない。画像の右クリックの「画像の下に操作バーを出す」でも切り替えられる）、終了・再起動のあとも浮かせていた画像を戻すか（初期設定はオン）、読み取った文字の吹き出しを外を押したら閉じるか（初期設定はオフ）、書き込みの影 |
| 保存 | 保存の仕方（毎回聞く / 決めたフォルダにすぐ保存）、保存先（1 つ。初期設定は `~/Pictures/Pinshot`。なければ自動で作る。ポップアップメニューから Finder で表示・その他…（ほかのフォルダを選ぶ）・初期設定に戻す）、種類ごとにフォルダを分ける（画像 / GIF / 動画）・月ごとにフォルダを分ける（2026-11 など。どちらも初期設定はオフ。分けたフォルダは、なければ保存するときに作る）、保存される場所の例。浮かせた画像の背景は、ここではなくツールバーの背景のボタンで決める（「次の画像にも使う」で、これから浮かせる画像の初期設定にもなる） |
| 履歴 | 撮った画像・読み取った文字・録画の残し方を、同じ形で 2 行ずつ並べる。1 行目は いまの量・「⋯」のメニュー（一覧を開く・Finder で開く・すべて削除…）・残すか（録画はいつも残す）、2 行目は 残す期間（1 日 / 1 週間 / 30 日 / ずっと）・残す数（画像と文字は 50 / 100 / 300 / 1000 件、録画は 10 / 20 / 50 / 100 本）。その下に一覧の表示（撮った画像 / 読み取った文字） |
| ショートカット | キャプチャ（範囲 / ウィンドウ / 画面全体 / スクロール / タイマー）、録画（画面を録画・録画中は止める）、浮かせた画像（クリップボード / 閉じた画像を戻す / すべて前に出す / すべて閉じる）、撮った画像の履歴に、それぞれ割り当てられる。ほかの操作と重なったら、そちらから外す。ほかのアプリが使っていて効かないときは、その行で知らせる |

## 2 つ以上のディスプレイ

- 範囲選択の画面は、すべての画面に出ます。モードのバーはマウスのある画面に付いていきます
- 画面ごとの解像度（Retina かどうか）のまま撮ります
- ディスプレイを外すなどして画面の外に出た画像は、見える画面に戻します
